# Kimina Lean Server - Client SDK
Client SDK for the Kimina Lean Server lies here.

[Kimina Lean Server](https://github.com/project-numina/kimina-lean-server) has gone a large change on commit "feat: refactor server" (ID: 1777d737465a10df02e77796dfcc2dd0eba15cc8) and dropped backwards support so it is not possible to use this library with the latest version of Kimina Lean Server. This library is tested on commit "fix: bump version to 1.0.1" (ID: 508c9235476cfde47120fc7ed49e81a71ed3708a) and client SDK is from that commit.
